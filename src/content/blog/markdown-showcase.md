# Markdown showcase: richer blog formatting

This post shows the richer Markdown features supported by the blog. It is useful as a template when writing future posts.

## Images and stickers

You can add images from the `public/images` folder:

![Website QR code example](/images/website-qr-code.jpg)

For stickers or icons, use small image files the same way:

```md
![My sticker](/images/my-sticker.png)
```

## Tables

| Feature | Supported | Example use |
| --- | --- | --- |
| Tables | Yes | Compare tools, results, metrics |
| Task lists | Yes | Track study or project progress |
| Images | Yes | Add diagrams, screenshots, stickers |
| Code blocks | Yes | Explain commands or snippets |

## Links and code

You can link to [GitHub Pages](https://pages.github.com/) and use inline code like `npm run build`.

```js
const post = {
  title: "My engineering note",
  tags: ["React", "AI", "Study"],
};
```
